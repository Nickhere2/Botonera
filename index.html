Ayuda y Atajos

Primeros Pasos

  • Añade Favoritos: Haz clic en el ícono de estrella en cualquier tarjeta para añadirla a tu sección de "Favoritos" y tenerla siempre a mano.
  • Búsqueda Global: Usa la barra de búsqueda en el menú lateral. Activa el interruptor de "Búsqueda Global" para buscar en todas las secciones a la vez.
  • Personaliza Categorías: Haz clic en los tres puntos al lado del título de una categoría para cambiar su nombre y color.

Atajos de Teclado

  • Ctrl + Alt + N : Agregar nuevo elemento
  • Ctrl + Alt + B : Activar barra de búsqueda
  • Ctrl + Alt + T : Cambiar tema visual
  • Ctrl + Alt + V : Cambiar modo de vista
  • Esc : Cerrar paneles y modales
