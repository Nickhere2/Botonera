¿Cómo Funciona?

Este es un centro de accesos personalizable para organizar tus links, buscadores, notas y más.

  • Conexión de Datos: La aplicación se conecta a un Gist de GitHub para guardar tus datos. La primera vez, se te pedirá un Gist ID. Para guardar cambios, necesitarás un Personal Access Token (PAT) de GitHub con el permiso gist.
  • Gestión de Categorías: Usa los botones que aparecen al pasar el ratón sobre un título de categoría para editarla o eliminarla. Para añadir una nueva, haz clic en "Nueva Categoría" o asigna un nombre de categoría nuevo al crear o editar un elemento.
  • Filtro Global: Usa la barra de filtro en el menú lateral para buscar elementos por título o etiqueta en la sección actual. Haz clic para expandirla y ver los filtros de etiquetas.
