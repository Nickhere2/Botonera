Atajos de Teclado

  • Ctrl + Alt + N : Agregar nuevo elemento
  • Ctrl + Alt + F : Activar barra de filtro
  • Ctrl + Alt + T : Cambiar tema visual
  • Ctrl + Alt + V : Cambiar modo de vista
  • Esc : Cerrar paneles y modales

¿Cómo Funciona?

Este es un centro de accesos personalizable para organizar tus links, buscadores, notas y más.

  • Inicio de Sesión: Inicia sesión con tu cuenta de Google para que todos tus datos se guarden y sincronicen en la nube. ¡Accede a ellos desde cualquier dispositivo!
  • Gestión de Categorías: Usa los botones y que aparecen junto a un título de categoría para editarla o eliminarla.
  • Filtro Global: Haz clic en el logo para activar la barra de filtro. Busca elementos por título o etiqueta en la sección actual.
